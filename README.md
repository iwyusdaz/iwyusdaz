# Hi, I'm Usada

Learning designer focused on evidence-based, accessible learning in the AI era.
My projects cover corporate L&D, K-12 and higher-ed curriculum, EdTech, and research skills.

## Instructional design case studies

Selected case studies from my instructional design portfolio. Each one sets out the performance problem, measurable objectives, a modality trade-off analysis, a 3D practice scene and an evaluation plan. The clients and scenarios are fictional, and none of the numbers are field results.

|---|---|

## Immersive 3D learning (three.js)

Five browser-based 3D learning games and mini courses. Realistic detail appears only where noticing it *is* the learning. The real data comes from NASA, USGS and the Smithsonian. There is no tracking and no sign-up, and every project has a text mode and full keyboard play.

**[Play them all in the Immersive Learning Lab →](https://immersive-learning-showcase.vercel.app/)**

| Project | What the learner does | Play |
|---|---|---|
| [Lunar Field Expedition](https://github.com/iwyusdaz/lunar-field-expedition) | Lands at the real Apollo 15 site, reads the terrain under changing sunlight, plans a sampling traverse and defends the findings | [Play](https://immersive-learning-showcase.vercel.app/play/lunar-field-expedition/) |
| [The Object Detective](https://github.com/iwyusdaz/object-detective) | Examines real Smithsonian 3D scans under raking light, checks them against archival records and writes an honest museum label | [Play](https://immersive-learning-showcase.vercel.app/play/object-detective/) |
| [Hazard Hunt](https://github.com/iwyusdaz/hazard-hunt) | Spots warehouse hazards in realistic 3D, replays a near-miss with pause-and-decide moments and practices reporting (workplace safety) | [Play](https://immersive-learning-showcase.vercel.app/play/hazard-hunt/) |
| [Field Ecologist](https://github.com/iwyusdaz/field-ecologist) | Designs a sampling plan for a meadow, then sees the true population and how the sampling design biased the estimate | [Play](https://immersive-learning-showcase.vercel.app/play/field-ecologist/) |
| [Glacier Time Machine](https://github.com/iwyusdaz/glacier-time-machine) | Aligns USGS repeat photos from 1941, 1950 and 2004 to real 3D terrain of Muir Inlet, Alaska, measures glacier retreat and reasons about causes and uncertainty | [Play](https://immersive-learning-showcase.vercel.app/play/glacier-time-machine/) |

These work best in a desktop or laptop browser, and phones get lighter graphics. Phone support has been checked in emulation only, not on physical phones. Functional, accessibility and performance testing is automated, and agent-based design reviews were run on earlier versions. No real learners have used these yet, and each repo's `STATUS.md` lists its known open issues.

## Open-source tools for learning designers

Each tool has negative tests that prove its checks catch seeded errors, and each has a separate agent review (labeled "Agent review") whose findings and fixes are committed in the repo.

| Tool | What it does | The gap it fills |
|---|---|---|
| [tracebook](https://github.com/iwyusdaz/tracebook) | Extracts factual claims from curriculum content, verifies each one against its cited source with quote-back matching, and rewrites approved corrections in place with dated notes. A weekly GitHub Action re-checks every source for link rot | Citations in course content go out of date without anyone noticing |
| [slidewalk](https://github.com/iwyusdaz/slidewalk) | Turns one lesson outline into a single-file HTML deck **and** a native PPTX. Accessibility checks (axe, keyboard, 320 px reflow, contrast, alt text) fail the build instead of warning | Deck generators treat accessibility as a claim rather than a gate |
| [chalkreel](https://github.com/iwyusdaz/chalkreel) | An agent skill that turns a measurable learning objective into a short, code-drawn explainer video with captions, a transcript and audio-description notes, checked against written criteria based on Mayer's multimedia principles | AI video generators start from a topic and optimize for engagement, not for a learning objective |
